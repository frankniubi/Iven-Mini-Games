# 太仓麻将规则（实现规格）

> 调研日期：2026-11-27。用途：给 4 人太仓麻将（机器人补位、蓝牙/Wi-Fi 联机）的工程实现。
> 写法：中文为主，`English notes` 用于实现细节。凡是工程师需要“照做”的地方都给出了唯一默认值；有争议的地方集中在第 10 节，并给出设置项（settings key）。

## 0. 阅读说明与可信度标记

每条规则后面用方括号标注依据：

| 标记 | 含义 |
|---|---|
| **[T]** | 有太仓专门来源直接支持（见第 11 节编号，如 [T:S2]） |
| **[T?]** | 有太仓来源，但来源之间有分歧、措辞含糊或被截断 |
| **[N:苏州]/[N:常熟]/[N:上海]** | 来自邻近玩法，太仓来源未提及，借用时已注明 |
| **[A]** | 推断/假设，无直接来源，需要找本地玩家确认 |

**来源格局（务必理解）：**

1. **线上主流版（同城游/边锋 “太仓麻将”）**：2016–2026 年一直有规则文本（百度百科、tcy365 多篇、同城游下载页、边锋 App 介绍），彼此措辞几乎一致，是**目前文档最完整、太仓玩家最可能熟悉的版本**。缺点：这些来源互相抄写，算不上相互独立的印证。
2. **聚闲麻将“太仓麻将”（2022，面向太仓本地亲友圈的 App）**：独立来源，其胡牌规则与第 1 类基本一致，另外有“辣子牌”，宣传特色为“百搭、掰杠头、买飘”。
3. **2013 年百度知道“太仓麻将怎么算低花和杠头”的网友回答**：一套**加法计花**（底 5 花、小门清 5、大门清 10、天胡 50 等），与百度百科“苏州麻将”的“具体算法”逐字相同。它可能是太仓线下较老的计法，也可能是苏州通用计法，两者谁抄谁无法确定。
4. **2013 年太仓人才网文章（棋聚堂）**：明确说“漂”和“掰杠头”是“太仓最本地”的规则，但没有解释怎么玩。

**结论：默认实现采用第 1 类（同城游/边锋）规则体系，补上第 2 类的“辣子”；第 3 类做成可切换的“苏州式加法计花”备选计分；“漂”“掰杠头”做成默认关闭的可选项。**

## 1. Summary 概述

太仓麻将是苏州太仓地区流行的 4 人麻将，用 **152 张牌**。最大特点是**“论花”计分**：中、发、白（带框）、不带框白板（大白板）、印字“百搭”牌，以及春夏秋冬、梅兰竹菊，**共 28 张全部是“花”**，摸到后亮出、从牌尾（杠头）补牌，每张记 1 花。牌桌上实际组牌的只有万/条/筒和东南西北。每局开牌时用骰子从牌墙**翻出一张牌**，按顺序取其“下一张”定为**财神（百搭，万能牌）**，例如翻 4 万则 5 万为财神，翻 9 万则 1 万为财神，翻春夏秋冬任一则梅兰竹菊全为财神。

胡牌门槛是**“二花自摸三花冲”**：不是门清又没有大牌牌型时，至少 2 花才能自摸，至少 3 花才能吃冲（点炮胡）。**门清（不吃不碰）不受花数限制**；门清且一个花都没有的自摸叫**“无花果”**，是太仓的最大牌。手里有财神不能吃冲胡，只能自摸。

计分方式：总花 = 底花 1 + 硬花 + 杠/风刻的花；每有 1 番就把总花翻一倍（门清、混一色、对对胡、杠开、大吊车各 1 番，清一色 2 番）。自摸三家各付，放冲由放冲者一家付。可以吃（只吃上家）、碰、杠，允许一炮多响。抢杠算自摸，由杠牌者一人付三份并做下一庄。“吃碰三口”要**承包**（被吃碰三口的那家付 5 倍）。没有风圈、门风，没有庄家加倍；胡牌者做下一庄，荒庄连庄。

### 1.1 太仓特有 vs 邻近玩法（防止混淆）

| 项目 | 太仓（默认） | 苏州麻将 [N:苏州] | 常熟麻将 [N:常熟] | 上海敲麻 [N:上海] |
|---|---|---|---|---|
| 牌数 | 152（28 花） [T] | 152（28 花，含老鼠/财神/猫/聚宝盆等花牌版本） | 144（12 花：4 白板+8 花） | 144（8 花，部分规则中发白也算花） |
| 中发白 | 全是花 [T] | 全是花 | 中、发可组牌（风暗杠含发财红中） | 可组牌（多数版本） |
| 万能牌 | 翻牌定“财神”（下一张） [T] | 有“百搭/将军牌”说法，版本不一 | 无 | 部分版本有百搭 |
| 吃 | 可吃，只吃上家 [T] | **不可吃** | 可吃 | 可吃（版本不一） |
| 起胡 | 二花自摸三花冲 [T] | 三花自摸四花冲（近年也流行二/三） | 二花自摸三花冲 | 须先“敲”（报听）才能胡 |
| 计分 | 底花 1 × 2^番 [T] | 加法：底 5 花 + 各项加花 | 加法：门清+5、清一色+10 等 | 花×番，以“勒子”封顶 |
| 特色 | 无花果最大、吃碰三口承包×5、辣子（4 财神）、漂、掰杠头 | 豹子/滴零翻倍、包饺子、送杠、七小对 | 剃头（抢杠）、字一色 15 花 | 敲响、勒子、开宝 |

“勒子”“敲响”属于上海敲麻，**太仓来源中均未出现**，不要用于太仓 UI。

## 2. Tiles 牌

### 2.1 牌张构成（152 张） [T:S1,S2,S11]

| 类别 | 牌 | 每种张数 | 小计 | 角色 |
|---|---|---|---|---|
| 万子 | 1万–9万 | 4 | 36 | 组牌 |
| 条子 | 1条–9条（1条俗称幺鸡） | 4 | 36 | 组牌 |
| 筒子（饼） | 1筒–9筒 | 4 | 36 | 组牌 |
| 风牌 | 东 南 西 北 | 4 | 16 | 组牌（字牌） |
| 箭牌 | 红中、发财、白板（**带框**） | 4 | 12 | **花** |
| 花牌 | 春 夏 秋 冬 梅 兰 竹 菊 | 1 | 8 | **花** |
| 特殊牌 | 印字“百搭” | 4 | 4 | **花**（除非被定为财神） |
| 特殊牌 | 白板（**不带框**，空白牌，旧称“大白板”） | 4 | 4 | **花**（除非被定为财神） |
| **合计** | | | **152** | 组牌 124 张 + 花 28 张 |

- **花 = 28 张**：4 中 + 4 发 + 4 白（带框）+ 4 白板（不带框）+ 4 百搭 + 8 花牌。每张 1 花。[T:S1,S5]
- 东南西北**不是花**，是正常组牌的字牌。
- 中发白**不能组牌**（没有中发白的碰、杠、对子）。唯一例外是它们被定为财神时（见 2.3）。
- 2023 年同城游教程只把春夏秋冬梅兰竹菊叫“花牌”并说要补花 [T?:S4]，但同城游其他文本和百科都明确 28 花。**默认以 28 花为准。**
- “印字百搭”牌本身**不是万能牌**，只是一张花。真正的万能牌是翻牌定出的“财神”。2017 年一篇同城游文章写“5 万就是财神”[T?:S9]，是把“翻 4 万则 5 万为财神”的例子误写成了固定规则，**不要实现固定 5 万**。

`English note`：tile kinds = 27 suited + 4 winds + 3 dragons + 8 flowers + BAIDA + BLANK = 44 kinds. 每张实体牌需要唯一 id（0–151）。8 张花牌各 1 张，其余每种 4 张。

### 2.2 财神（百搭/万能牌）由翻牌决定 [T:S1,S2,S4,S5]

每局开牌后翻出一张**翻牌（indicator）**。翻牌**移出本局**，开打用 151 张。按下表取它的“下一张”，**该种牌的全部实体牌**为本局财神：

| 翻出的牌 | 本局财神 |
|---|---|
| n万/n条/n筒（n=1..8） | 同花色 n+1 |
| 9万/9条/9筒 | 同花色 1（例：翻 9 条 → 幺鸡为财神 [T:S4]） |
| 东 → 南 → 西 → 北 → 东 | 循环下一张（翻北 → 东） |
| 红中 → 发财 → 白板(带框) → 红中 | 循环下一张。“白→中”为 [A] 推断，来源只写了“红中－发财－白板（带框）”的顺序 |
| 春/夏/秋/冬 任一张 | 梅、兰、竹、菊 4 张都是财神 |
| 梅/兰/竹/菊 任一张 | 春、夏、秋、冬 4 张都是财神 |
| 印字百搭 | 白板（不带框）4 张为财神 |
| 白板（不带框） | 印字百搭 4 张为财神 |

财神总是 4 张实体牌。翻牌只有 1 张，且属于另一个牌种，所以财神那一种的 4 张都在牌墙里。

### 2.3 财神的属性（实现约定）

| 规则 | 默认 | 依据 |
|---|---|---|
| 财神可代替任意一张组牌（万条筒风），也可当它本身用 | 是 | [T] |
| 财神属于花类牌种时（如发财、梅兰竹菊、百搭、白板），**不补花，也不计花**，留在手里当万能牌 | 是 | [A]，逻辑必然：一张牌不能既是万能牌又立即补掉 |
| 手里有财神（不论是否当本身用）**不能吃冲胡**，只能自摸（含杠开、抢杠） | 是 | [T:S2,S3,S4] |
| 财神**不能用于吃、碰、明杠**；4 张财神也不能开杠（见“辣子”） | 是 | [A]，参照通行百搭玩法 |
| 财神可以打出；打出的财神**任何人不能吃、碰、杠、胡** | 是 | [A] |
| 判定清一色、混一色、对对胡、七对等牌型时，财神按它所代替的牌计算 | 是 | [A] |
| 用财神凑成的风刻按风刻计花（例：东东+财神=东刻，记 1 花） | 是 | [A] |

## 3. Seats, dealer, and round structure 座位、庄家与局制

### 3.1 座位与方向

- 座位 `seat 0..3`。行牌顺序 `0→1→2→3→0`。`下家(i) = (i+1)%4`，`上家(i) = (i+3)%4`，`对家(i) = (i+2)%4`。俯视为逆时针，与中国麻将惯例一致。[T:S4]“从庄家开始，逆时针出牌”
- **不分门风、圈风**：所有风牌地位相同，任何风刻都按“风”计花，不存在“自风/圈风”加花。[A]，太仓所有来源都没有门风/圈风概念

### 3.2 首局定庄

- 同城游：第一局**系统随机**指定庄家 [T:S3,S2]。
- 默认：随机选庄，客户端可以播放“掷骰定庄”动画（各家掷骰点数最大者为庄）作为表现。线下惯例是掷骰，这一点为 [A]。

### 3.3 连庄与换庄 [T:S1,S2,S10,S11]

| 情况 | 下一局庄家 |
|---|---|
| 庄家胡牌 | 庄家不变（连庄） |
| 闲家胡牌（自摸或吃冲） | 胡牌者坐庄 |
| 抢杠胡 | **被抢杠的人（杠牌者）**坐庄 [T:S1,S10,S11] |
| 荒庄/黄庄（牌摸完无人胡） | 庄家不变 [T:S2] |
| 一炮多响 | 按行牌顺序，从放冲者的下家起第一个胡牌者坐庄；庄家在胡牌者之中时庄家连庄 [A] |
| 辣子（4 财神直接胡） | 胡牌者坐庄（同自摸） [A] |

- **庄家没有任何额外收付**：不翻倍，不加底。[T] 所有太仓计分示例都没有庄家因素
- 庄家起手 14 张，先打牌。

### 3.4 局制

- 太仓来源**没有**“风圈”（东风圈、南风圈……），每局独立结算 [T:S2]（“结束标志：有玩家胡牌或者抓完所有牌”）。
- 一场打多少局没有本地规定。线上按局结算；亲友圈类 App 常见“8 局/16 局”房间 [A]。
- **默认：房间设置 `handsPerSession`=8，可选 4/8/16/不限；不设风圈；累计分数显示在结算页。**
- **没有每场封顶/“勒子”**（勒子是上海敲麻概念）。单局封顶见 7.4。

## 4. Dealing and flowers 砌牌、发牌与补花

### 4.1 牌墙

- 152 张，4 面墙，每面 **19 墩 × 2 层 = 38 张**。[N:苏州 S23]“每个风圈19排”；152/4/2 = 19，太仓同牌数
- `English note`：洗牌用 CSPRNG（联机时由房主/权威端洗牌并广播 seed 或牌序）。牌墙在逻辑上建模为一个 **deque**：`front` 是正常摸牌端，`back` 是**杠头**（补花、补杠的摸牌端）。下面的骰子/墩数只决定动画中从哪里开门，不影响随机性。

### 4.2 掷骰开门与翻财神

**默认（同城游现行）[T:S2,S4]：**

1. 庄家同时掷 2 颗骰子，点数为 `d1, d2`。
2. **点数和** `S = d1+d2` 决定从谁面前的墙开门：从庄家起逆时针数，`(S-1)%4`：0=庄家，1=下家，2=对家，3=上家（即 1/5/9 数到庄家，2/6/10 下家，3/7/11 对家，4/8/12 上家）。
3. **大点数** `L = max(d1,d2)` 决定开门墩数：在该墙上从右往左数 L 墩，从第 L+1 墩开始正常摸牌；第 L 墩及更右边的牌是牌尾（杠头方向）。
4. **小点数** `s = min(d1,d2)` 决定财神：从开门处向牌尾方向数第 s 墩，翻开其上层牌作为**翻牌**，按 2.2 定财神。翻牌移出牌墙（剩 151 张）。

**备选（百度百科写法）[T?:S1]**：只用点数和 S，开门在对应墙的第 S+1 墩，翻牌取开门处牌尾一侧第 S 墩。原文“对家的下家第7幢”有歧义。设置项 `diceMode: 'tcy' | 'baike'`，只影响动画。

### 4.3 发牌 [T:S1,S2]

- 庄家 14 张，闲家各 13 张。
- 表现：从庄家起按行牌顺序，每人每次拿 4 张，共 3 轮；然后庄家拿 2 张（跳牌），闲家各拿 1 张。[A] 通行惯例，来源只写“庄家抓第一4张牌”
- `English note`：逻辑上就是从 `front` 依次 pop。

### 4.4 补花 [T:S1,S4] / [N:苏州 S23]

1. **起手补花**：发牌后、庄家出第一张牌前，从**庄家开始按行牌顺序**，每人把手中所有花（非财神的 28 种花类牌）亮出，放到自己的花区，从**牌尾（杠头，`back`）**补同样张数。补上来的还是花就继续亮、继续补，直到没有花。轮完一圈即结束；后面的人补到花各自处理，不再回头轮。
2. **行牌中补花**：任何时候摸到花（正常摸牌或补牌），立即亮出，并从 `back` 补一张。补到的牌如果正好胡，就是**杠开（花开）**，见 7.2。[T:S1]“当抓到花或是杠牌后，应该在拿牌的另一侧补上一张牌”
3. 亮出的花**公开可见**，只在自己胡牌时计花。
4. 财神不补（见 2.3）。

### 4.5 牌尾与荒庄

- **不留牌**：牌**全部摸完**为止 [T:S2]（“抓完所有牌”“结束标志：有玩家胡牌或者抓完所有牌”）。默认 `reservedTiles = 0`。
- 最后一张牌摸完、此人打出的牌也无人胡，即**荒庄（黄庄）**，不结算，庄家连庄。
- 最后一张牌：摸牌者可以自摸；不胡就必须打出，其他人可以吃冲胡这张牌，但不能吃、碰、杠它（没有下一张可摸）[A]。
- `back` 端（补牌）与 `front` 端（正常摸）共用一个 deque。剩 0 张时不能开杠（无牌可补）[A]。

## 5. Turn actions 行牌动作

### 5.1 基本回合

1. 轮到的人从 `front` 摸 1 张。是花就按 4.4 补花。
2. 摸牌后可以：**自摸胡**、**暗杠**、**补杠（加杠）**（这些动作可以连续做）。都不做就打出 1 张。
3. 别人打出一张牌后，按 5.6 的优先级处理吃/碰/杠/胡。
4. 吃、碰之后**不摸牌**，直接打 1 张；明杠之后从 `back` 补 1 张再打。

### 5.2 吃 [T:S1,S2,S3]

- **只能吃上家**打出的牌，组成同花色顺子。风牌不能吃。
- 吃之后打出的牌没有限制（来源没有上海式“吃了不能打同一张”的规定）。默认无限制，设置项 `chiDiscardRestriction:false`。

### 5.3 碰 [T]

- 任何一家打出的牌，手里有 2 张相同的牌都可以碰（万条筒风）。

### 5.4 杠 [T:S1,S5]

| 类型 | 条件 | 计花（胡牌时才计，见 7.1） |
|---|---|---|
| 明杠·直杠（一次杠） | 手里有 3 张，别人打出第 4 张 | 数牌 1 花 / 风 2 花 |
| 明杠·补杠（续杠、先碰后杠） | 自己已碰的牌，自己摸到第 4 张（或手里留有第 4 张），在自己回合加杠 | 数牌 1 花 / 风 2 花 |
| 暗杠 | 自己手里 4 张，在自己回合开杠 | 数牌 2 花 / 风 3 花 |

- 开杠后从 **`back`（杠头）**补 1 张。补到花就继续补。补牌后胡牌就是**杠开**。
- 补杠可以被**抢杠**（5.5）。直杠、暗杠不能被抢。
- 碰的时候本可以杠而选择了碰：之后在自己的回合可以补杠（不必非要“下一次摸牌后”才行，这与苏州“必须等摸牌后”的规定效果一样）[N:苏州]。
- **杠没有即时收付**（杠钱/刮风下雨不存在），杠只在自己胡牌时提供花数 [T]。
- 暗杠的展示：默认对他人显示为暗牌（4 张背面）；设置项 `revealOneOfAnGang`（苏州习惯翻开 1 张）[N:苏州]。

### 5.5 抢杠 [T:S1,S10,S11]

- 某人补杠时，任何能胡这张牌的人都可以**抢杠胡**。抢杠**按自摸计算**（门槛用自摸门槛 2 花，财神禁冲规则不适用）。
- 收付：**由杠牌者一人付三份**（相当于替三家付自摸钱）[T]。
- 抢杠成功后补杠作废，杠牌者保留原来的碰。**下一局由杠牌者坐庄** [T]。
- 允许**多人同时抢杠**，杠牌者分别付每位胡家三份 [N:苏州]，与太仓允许一炮多响一致 [A]。

### 5.6 声明优先级

1. **胡** > **杠/碰** > **吃**。
2. 多人胡同一张：**一炮多响**，全部胡 [T:S2,S3]。不做截胡。
3. 碰/杠与吃冲突时，碰/杠优先（碰、杠不可能两人同时满足）。
4. `English note`：每次有人出牌，向所有有可选动作的玩家开放一个声明窗口（机器人立即决定；真人默认 15 秒倒计时，超时视为“过”）。收齐或超时后按优先级裁决。

### 5.7 过碰、过胡（漏碰/漏胡） [T:S2]

同城游原文：“放弃过的碰张一圈内不能再碰，放弃过的胡张一圈内不能再胡”。

- **过碰**：放弃碰 X 之后，到自己下一次摸牌之前，不能再碰 X。
- **过胡**：放弃一次可以吃冲胡的机会之后，到自己下一次摸牌之前，**不能吃冲胡任何牌**（不只是同一张）。苏州规则写明“同样或者能胡的牌”都不行 [N:苏州]。自己摸牌后解除，自摸不受影响。
- 自摸时选择不胡而打出一张，同样进入过胡状态，直到下次摸牌 [N:苏州]。

### 5.8 其他限制

- **没有报听/听牌声明**（不同于上海敲麻的“敲”）[T]，所有太仓来源都没有。
- **起胡门槛**：二花自摸三花冲，门清及大牌豁免，详见 6.3。
- **手里有财神不能吃冲胡** [T]。
- **诈胡**：线下的规矩是诈胡者向其他三家各付同等费用 [T:S1]；数字版**直接禁止**非法胡牌（只有合法时才出现“胡”按钮），与同城游“系统中将禁止诈胡产生”一致。

## 6. Winning hands 胡牌牌型

### 6.1 基本胡型

- **4 组（顺子或刻子/杠）+ 1 对（头子）**，共 14 张（杠按 3 张算）。[T]
- **七对**（7 个对子，必须门清，不能有任何副露）：同城游列为牌型 [T:S3]。4 张相同的牌可以当 2 对 [A]。**豪华七对不单独计**（来源没有）[A]。
- **十三幺**：太仓牌制里**不可能成立**（中发白是花），也没有来源，不实现。
- **字一色**：太仓没有来源，不单独计（常熟有，记 15 花 [N:常熟]）。

### 6.2 牌型定义（用于计番，见 7.2）

| 牌型 | 判定（实现定义） | 依据 |
|---|---|---|
| （门前清状态） | 本局**没有吃、碰、明杠**（暗杠可以；亮花不影响）。这是辅助判定，不计番 | [T] 不吃不碰；“不明杠”取自 [N:苏州] |
| 门清 | 门前清状态，且门槛花（底花以外）≥1 | [T]；“且有花”取自 [T:S11] |
| 无花果 | 门前清状态，且**门槛花 = 0**（无硬花、无杠、无风刻） | [T:S1,S11] |
| 混一色 | 只有一种数牌花色 + 风牌，且至少有 1 张风牌 | [T] |
| 清一色 | 只有一种数牌花色，没有风牌 | [T] |
| 对对胡（碰碰胡） | 4 组都是刻子/杠 + 1 对（副露、暗刻都行） | [T] |
| 七对 | 见 6.1 | [T:S3] |
| 杠开（含花开） | 用杠后或补花后从杠头补来的牌胡牌 | [T] |
| 大吊车（金钩吊） | 已有 4 组副露（吃/碰/明杠/暗杠），手里只剩 1 张单吊，胡这张（自摸或吃冲都可以） | [T]。“吃”是否算副露见第 10 节 |
| 抢杠 | 胡别人补杠的那张牌 | [T] |
| 辣子（辣子牌） | 一局中手里同时持有本局全部 4 张财神，可以立即宣布胡（不需要成牌型） | [T?:S11] 聚闲独有 |

### 6.3 起胡门槛：二花自摸三花冲 [T:S1,S2,S11]

定义：**`门槛花数 = 硬花 + 杠花 + 风刻花`**（即总花**减去底花**）。

| 胡法 | 要求 |
|---|---|
| 自摸（含杠开、花开、抢杠） | 门槛花数 ≥ 2 |
| 吃冲（点炮胡） | 门槛花数 ≥ 3，**且手里没有财神** |
| **豁免**：手牌有任意一个“番”牌型（门清、混一色、清一色、对对胡、七对、杠开、大吊车）或是无花果、辣子 | 不受花数限制（财神禁冲照样适用） |

抢杠本身不算番，所以没有番型的抢杠按**自摸门槛（2 花）**判定（第 10 节第 20 项）。

- 豁免范围的依据：百科把规则分成“小胡（二花自摸三花冲）”和“大胡（门清、混一色、清一色、对对胡、杠开、大吊车、抢杠）”，门槛只针对小胡。聚闲称之为“基本胡：二花（吃或碰或杠过牌）自摸、三花点炮”。苏州版本明确规定大牌不受门槛限制 [N:苏州]。
- 门槛按**胡牌后的完整手牌**计算：胡牌那张牌凑成的风刻也算花。

### 6.4 胡牌判定的财神处理

`English note`：手牌判胡时把财神当万能牌做回溯（每张财神尝试 34 种可组牌 + 不用）。数牌 27 种 + 风 4 种 = 31 种可组牌（中发白不可组）。同一手牌能拆成多种组合时，**取计分最高的拆法**（[A]，通行做法）。

## 7. Scoring 计分

### 7.1 花的计算 [T:S1,S2,S5]

| 项目 | 花数 | 备注 |
|---|---|---|
| **底花** | **1** | 胡牌必得 |
| 硬花（每张亮出的花：中、发、白、白板、百搭、春夏秋冬梅兰竹菊） | 每张 1 | 财神不计 |
| 数牌刻子（碰或暗刻） | 0 | |
| 数牌明杠（直杠、补杠） | 1 | |
| 数牌暗杠 | 2 | |
| 风刻（碰或暗刻，即“胡牌后手上有 3 张相同的风”） | 1 | 碰来的也算 [T:S5]“明刻暗刻1花” |
| 风明杠 | 2 | |
| 风暗杠 | 3 | |
| 风对子、单张风 | 0 | |
| 中发白的碰/杠 | 不存在 | 它们是花 |

- 只有**胡牌者**计花；输家的花和杠不计任何东西。
- 邻近玩法不同：苏州/常熟/2013 加法表是“风碰 1、风暗刻 2、风明杠 3、风暗杠 4”，**太仓线上版是 1/1/2/3**。不要混用。

### 7.2 番（翻倍） [T:S1,S2,S4]

每 1 番，总花翻一倍：1 番 ×2，2 番 ×4，3 番 ×8，以此类推。**所有番累加**。

| 番种 | 番数 | 倍数 | 依据 |
|---|---|---|---|
| 门清（不吃不碰，有花） | 1 | ×2 | [T] |
| 混一色 | 1 | ×2 | [T]（原文“翻2倍”= ×2） |
| 清一色 | **2** | ×4 | [T]“清一色（2番）……花翻4倍” |
| 对对胡 | 1 | ×2 | [T] |
| 七对 | 1 | ×2 | [A]：同城游只列了牌型没给数值，见第 10 节 |
| 杠开（杠后开花、花开） | 1 | ×2 | [T] |
| 大吊车 | 1 | ×2 | [T] |
| 抢杠 | 0（按自摸付款方式） | — | [T] |
| 自摸 | 0（但三家各付） | — | [T] |
| 庄家 | 0 | — | [T] |

七对一定是门清，所以默认七对同时计门清 1 番（合计 ×4）。[A]

### 7.3 结算公式

```text
门槛花 = 硬花 + 杠花 + 风刻花
总花 T = 底花(1) + 门槛花
番 F   = Σ 牌型番数
单家花 P = min( T × 2^F , 封顶 C )            // C 默认 100，见 7.4
金额 = 花 × 每花单价（房间设置，默认 1 分/花；俗称“一角头”=每花一角）
```

**无花果**、**辣子**不走这个公式，直接按封顶计（7.4）。

`English note`（伪代码）：
```ts
function settle(win): Payment[] {
  if (win.type === 'lazi') return others.map(p => pay(p, win.player, C));      // 辣子：三家各付封顶
  if (win.isWuhuaguo) return win.selfDraw
      ? others.map(p => pay(p, win.player, C))                                 // 无花果自摸：三家各付封顶
      : [pay(win.discarder, win.player, Math.floor(C / 2))];                   // 无花果吃冲：放冲者付封顶一半
  const T = 1 + win.hardHua + win.gangHua + win.windHua;
  const P = Math.min(T * 2 ** win.fan, C);
  if (win.type === 'qianggang') return [pay(win.konger, win.player, 3 * P)];
  if (win.selfDraw) {                                                          // 含杠开/花开
    const bao = chengbaoPayer(win);                                            // 吃碰三口
    return bao ? [pay(bao, win.player, 5 * P)] : others.map(p => pay(p, win.player, P));
  }
  return [pay(win.discarder, win.player, P)];                                  // 吃冲
}
```

### 7.4 封顶、无花果、辣子

- 原文“太仓自摸‘无花果’算是最大牌，出冲‘无花果’算付最大的一半”[T:S1]。由此推断存在一个“最大”金额（封顶）。**默认封顶 C = 100 花/每个付款人**，可设 50/100/200/不封顶。[A]：数值来源没给；同城游文中“比如付100两银子”只是举例
- **无花果自摸**：三家各付 C。
- **无花果吃冲**：放冲者付 C/2 [T:S1]。注意：聚闲规定无花果“必须自摸”[T?:S11]，设置项 `wuhuaguoAllowDiscard`，默认 `true`（同城游）。
- 设为“不封顶”时，无花果改用固定值 `wuhuaguoHua`（默认 100）。
- **辣子**：手持全部 4 张财神时，可在自己回合（摸牌后，或庄家起手）宣布胡，按自摸、三家各付 C 结算，**不适用承包** [A]。是否计入胡牌、怎么付钱，聚闲都没说明；“辣子”在江南麻将里通常指封顶，故按封顶 [N:上海]。

### 7.7 计算示例（默认规则，封顶 C=100，1 花=1 分）

> 记号：`[碰 东东东←P]` 表示从 P 那里碰来；`(花: 红中 春)` 表示已亮出的花。

**例 1：小胡自摸（无番）**
- 翻牌 西 → 财神 = 北。闲家 B 胡，手里没有北。
- B：(花: 红中 春)；`[吃 3万4万5万←上家]` `[碰 5条5条5条←对家]`；暗手 `6筒7筒8筒` `东东东` `9万`，自摸 `9万`。
- 花：底 1 + 硬花 2 + 东暗刻 1 = **4**；门槛花 3 ≥ 2，可以自摸。
- 番：不是门清（有吃碰），不是一色，不是对对 → 0 番。P = 4。
- 结算：A、C、D 各付 4，**B +12**。
- 如果这张 9万 是别人打出的：门槛花 3 ≥ 3 且 B 手里没有财神，可以吃冲，放冲者付 4。

**例 2：门清清一色自摸（与百科原例一致）**
- 翻牌 东 → 财神 = 南。庄家 A。
- A：(花: 发财 白板(不带框) 夏 菊 百搭) 共 5 硬花；暗手 `1万1万1万 2万3万4万 5万6万7万 7万8万9万 9万`，自摸 `9万`。
- 花：1 + 5 = **6**。番：门清 1 + 清一色 2 = 3 → ×8。P = 6×8 = **48**。
- 结算：三家各付 48，A +144。按 5 银子/花即每家付 240，与百度百科示例“(5花+1底花)×4×2=48花……每人应该给付240银子”一致。

**例 3：对对胡 + 混一色 + 杠开 + 承包**
- 翻牌 2筒 → 财神 = 3筒。C 胡，P 是另一家。
- C：(花: 红中 白板(带框) 梅) 3 硬花；`[碰 东东东←P]`（1 口）`[碰 7条7条7条←P]`（2 口）；暗手 `9条9条9条 3条3条 西西`。
- P 打出 9条，C **直杠**（第 3 口，承包成立），从杠头补到 `3条` → 和：东刻、7条刻、9条杠、3条刻、西对。
- 花：1 + 3 + 东碰 1 + 9条明杠 1 = **6**。番：对对胡 1 + 混一色 1 + 杠开 1 = 3 → ×8。P = **48**。
- 杠开按自摸，但 C 对 P 已吃碰杠三口 → **P 一人付 48×5 = 240**，另外两家不付。C +240。
- （关闭承包时：三家各付 48，C +144。）

**例 4：抢杠**
- A 早先碰了 6筒，现在摸到第 4 张 6筒，宣布补杠。
- B：门清，(花: 兰 发财)；暗手 `1万2万3万 4万5万6万 7条8条9条 4筒5筒 南南`，听 3筒/6筒 → **抢杠**胡 6筒。
- 花：1 + 2 = **3**。番：门清 1 → P = 6。
- 结算：**A 一人付 3×6 = 18**；A 保留碰 6筒；**下一局 A 坐庄**。
- 如果 D 也听 6筒：D 同时抢杠，A 另外付 D 三份（按 D 的牌计）。

**例 5：无花果（含财神）**
- 翻牌 4万 → 财神 = 5万。C 全局没摸到花，门清，无杠，无风刻。
- C：暗手 `1条2条3条 4条5条6条 7筒8筒9筒 2万3万 5万(财神，当4万) 南`，自摸 `南` → 南对。
- 底花以外 0 花，门清，自摸 → **无花果**：三家各付封顶 **100**，C +300。
- C 手里有财神，所以这张南如果是别人打的，**不能吃冲**。若 C 没有财神且吃冲成无花果：放冲者付 50。
- 对比：如果不按无花果、只按门清公式算，这手只有 1×2 = 2 花。无花果的意义正在这里。

**例 6：一炮多响 + 门槛拦截**
- 座位 A(0) B(1) C(2) D(3)，D 打出 8万。A、B、C 手里都没有财神。
- A：`[碰 东东东]`，(花: 中 秋 百搭) 3 硬花；暗手 `2万3万4万 4条5条6条 6万7万 9筒9筒`。门槛花 = 3+1 = 4 ≥ 3，可以吃冲。花 1+3+1 = **5**，0 番 → D 付 5。
- B：`[吃 1万2万3万]`，(花: 冬 竹) 2 硬花；暗手 `5条6条7条 2筒3筒4筒 7万9万 南南`，也能成 8万嵌张。门槛花 2 < 3 且没有番型 → **不出现“胡”按钮**。
- C：门清，(花: 菊) 1 硬花；暗手 `3条4条5条 6筒7筒8筒 1筒2筒3筒 6万7万 2条2条`。门清豁免，可以胡。花 1+1 = 2，门清 ×2 → D 付 **4**。
- 结算：D 共付 9（A +5，C +4）。下一庄：从 D 的下家起第一个胡家 = **A**。

**例 7：同一手牌在备选“苏州式加法”下（对比用）**
- 例 2 的牌：底 5 + 硬花 5 + 小门清 5 + 清一色 10 = **25 花**/家（默认规则是 48）。

### 8.1 承包细则 [T?:S1,S2,S3,S5]

来源原文：
- “承包：吃碰三口要承包。承包是总的花数x5，且由承包家一个人付，有多家承包关系需要……”（后面被截断）[S5,S6]
- “吃碰杠同一家超过三次，如果该玩家胡牌，则被吃碰杠的玩家承担5倍积分”（2022）[S3]
- “如果吃碰3口的自摸，被吃碰的那家要付5倍”（同城游下载页，现行）[S2]

**默认实现：**
1. 计数：本局中胡家从同一家 X 处**吃、碰、直杠**（拿 X 打出的牌）的次数。补杠、暗杠不计。
2. 计数 **≥3** 即承包关系成立（“三口”）。由于最多 4 组副露，同一时间最多只有一个承包家。
3. 只在胡家**自摸/杠开/花开**时生效：X 付 5P，其他人不付。
4. 胡家吃冲（不论谁放冲）时**不适用承包**，按普通吃冲结算。设置项 `chengbaoOnDiscard: 'off' | 'baojia-pays-5x'`。
5. 抢杠、无花果、辣子不适用承包（抢杠由杠者付；无花果必然门清；辣子固定封顶）。
